# Stage 05: YOLO Commit Flow (`--yolo` only)

Load this only when `--yolo` is enabled and `speckit-code-review` is already `pass`.

## Behavior

1. Skip all human review/approval interactions.
2. Auto-generate commit message:
   - `feat(<spec-id>): <short summary from spec.md or Jira summary>`
3. If git submodules exist and were modified:
   - Commit each modified submodule first:
     - `git add -A`
     - `git commit -m "<auto-generated-commit-message>"`
   - Then commit in parent repo to record submodule pointer update (and any parent changes):
     - `git add -A`
     - `git commit -m "<auto-generated-commit-message>"`
4. If no modified submodules, run parent commit as current behavior:
   - `git add -A`
   - `git commit -m "<auto-generated-commit-message>"`
5. Report commit message + hash.

## Notes

- If commit fails, stop and report exact failure.
- Spec completion step still runs after this stage.
