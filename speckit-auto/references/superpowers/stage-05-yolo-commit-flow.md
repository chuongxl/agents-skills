# Stage 05 (superpowers): YOLO Commit Flow (`--yolo` only)

Load this only when `--yolo` is enabled and `speckit-code-review` is already `pass`.

## Behavior

1. Skip all human review/approval interactions.
2. Auto-generate the commit message:
   - `feat(<issue_id>): <short summary from the design spec or Jira summary>`
3. If git submodules exist and were modified:
   - Commit each modified submodule first:
     - `git add -A`
     - `git commit -m "<auto-generated-commit-message>"`
   - Then commit in the parent repo to record the submodule pointer update (and any parent changes):
     - `git add -A`
     - `git commit -m "<auto-generated-commit-message>"`
4. If no submodules were modified:
   - `git add -A`
   - `git commit -m "<auto-generated-commit-message>"`
5. Report the commit message + hash.

## Notes

- If a commit fails, stop and report the exact failure.
- `finishing-a-development-branch` is not invoked in YOLO mode.
- The completion step (Stage 06) still runs after this stage.
